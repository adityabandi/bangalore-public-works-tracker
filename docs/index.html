How We Detect Anomalies

Cost Outliers

Flags orders exceeding 3x the interquartile range above Q3 within their ward-category group. Minimum threshold: ₹5 lakhs.

Duplicate Work

Detects similar work descriptions (Jaccard similarity ≥ 0.85) within the same ward in a 12-month window.

Split Orders

Identifies 3+ orders clustered just below procurement thresholds (₹5L, ₹10L, ₹25L, ₹50L, ₹1Cr) within 15% band.

Payment Speed

Flags orders paid in the bottom 5th percentile for turnaround time — suspiciously fast approvals.

Benford's Law

Tests first-digit distribution of amounts per ward against expected natural distribution (chi-squared, p<0.05).

Contractor Concentration

Flags contractors controlling >15% of a ward's orders or >5% of citywide orders.

Bid Anomaly

Compares order costs against Karnataka SoR 2024-25 benchmark rates. Flags orders >2x ward-category median.

Deduction Ratio

Flags unusual deduction/gross ratios (beyond 2.5x IQR) — potential accounting manipulation.

Repeat Work

Detects identical work types at the same location across 3+ fiscal years — chronic budget cycling.

Repeat Contractor

Flags contractors with >30% of ward-category orders — potential favoritism patterns.

Data Sources: All work order data sourced from OpenCity.in (BBMP's open data portal). Tender data from BBMP e-procurement records (2013-2018). Ward boundaries from DataMeet. Cost benchmarks from Karnataka Schedule of Rates 2024-25.

Pipeline: Data is fetched, normalized, and analyzed daily via automated pipeline. Source code on GitHub.
